# TrollAC

Troll cheaters instead of banning them — with TrollAC.

> **Beta Notice:** TrollAC is currently in beta. Features may change and bugs may occur.

TrollAC is a Minecraft anti-cheat inspired by GrimAC that takes a different approach: instead of banning players, it applies creative trolling mechanisms to discourage cheating.

---

## Features

- Advanced cheat detection based on GrimAC principles
- Non-punitive approach using trolling instead of bans
- Lightweight and efficient performance
- Simple configuration
- Web-based dashboard for management and monitoring

---

## How It Works

Instead of removing cheaters from the server, TrollAC interferes with their gameplay in controlled and often unexpected ways. This approach discourages cheating while keeping players engaged.

---

## Dashboard & Registration

TrollAC requires registration through the official web dashboard.

Website: http://trollac.wsites.qzz.io

Through the dashboard, you can:
- Register and manage your server
- Monitor detections and activity
- Configure trolling behaviors
- Access future updates and features

## Installation

1. Download the latest release  
2. Place the `.jar` file in your server's `plugins` directory  
3. Start the server  
4. Register your plugin on the dashboard  
5. Configure settings via the web interface or config files
